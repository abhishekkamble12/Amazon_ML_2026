# Business Entity Resolution ML Challenge

This repository contains the codebase and project structure for the Business Entity Resolution Challenge.

## Environment & Workflow Setup
- **Development Environment**: Local development and prototyping are performed using VS Code / local machine.
- **Compute & Training**: Google Colab will later be utilized for large-scale computation and model training.
- **Version Control**: GitHub serves as the central source of truth for all code, configs, and documentation.
- **Datasets**: Dataset files are intentionally not included in the repository. Place raw datasets locally in the `data/` directory.
- **Implementation Status**: This repository currently contains only the initial project skeleton. The machine learning pipeline, data processing, and modeling components will be implemented in subsequent phases.
